Debugging Techniques

CSS Check in Website

When a website's layout breaks or elements aren't aligning correctly, 
inspecting and debugging your CSS is the fastest way to find the culprit 
Here is a quick-reference guide on how to perform a thorough 
CSS check using browser Developer Tools (DevTools)

1. Open the Inspector: Right-click on the problematic element on your 
  webpage and select "Inspect" (or press F12 / Cmd + Option + I)

2. Verify the Box Model: Use the DevTools layout panel to check the 
  element's padding, border, and margin. Unexpected spacing is 
  often caused by default browser margins or forgotten padding.

3. Track Down Overridden Styles: Look at the Styles tab. If a CSS rule 
  has a strikethrough line, it means another rule with higher specificity 
  or a later cascade position is overriding it.
4.Toggle Styles on the Fly: Uncheck the boxes next to individual CSS 
  properties in DevTools to temporarily disable them. This helps isolate 
  exactly which property is causing the visual bug.
